Single-database configuration for Flask.

This directory contains Alembic/Flask-Migrate migration files for the
Joo Optics API.

## If you're starting fresh (no existing database)

```bash
flask db upgrade
```

This creates all 7 tables (users, products, shipping_addresses,
prescriptions, orders, order_items, payments) via revision a1b2c3d4e5f6.

## If you already have a populated site.db

The existing `site.db` (or `test_debug.db`) was created directly via
`db.create_all()`, not through Alembic, so it has no migration history.
Running `flask db upgrade` against it as-is will fail with "table already
exists". Instead, tell Alembic this database is already at the initial
revision:

```bash
flask db stamp a1b2c3d4e5f6
```

From then on, any future model change should go through the normal flow:

```bash
flask db migrate -m "describe the change"
flask db upgrade
```

Always read the autogenerated migration before applying it - Alembic's
diffing is good but not perfect (e.g. it won't always detect a column
rename correctly, and it won't fill in data for a new NOT NULL column
added to a table that already has rows).
